我的網頁設計學習之路

分類：程式學習 | HTML5

這學期開始接觸網頁前端程式設計， 第一個學習的技術就是 HTML。

HTML 負責建立網頁的基本結構， 透過不同的標籤， 可以將文字、圖片、連結 與其他內容放進網頁。

目前接觸的 HTML 標籤

  • <header>：頁首
  • <nav>：導覽列
  • <main>：主要內容
  • <section>：內容區塊
  • <article>：獨立文章
  • <footer>：頁尾

希望之後學會 CSS 和 JavaScript， 能讓網站不只有內容， 還能擁有更好的外觀與互動效果。
